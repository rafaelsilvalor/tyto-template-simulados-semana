# tyto-template-simulados-semana

`simulados-semana`, a [Tyto](https://github.com/rafaelsilvalor/tyto) code template in its own
repository: the week's mock exams as a carousel and as stories. It replaces Tyto's three
built-in `simulados-semana-roxo`, `-ocre` and `-vinho` with one template and three
configurations (TYTO-441, Tyto ADR 0151 and ADR 0155).

Work in progress: the template lands on `feat/TYTO-441-simulados-semana`.
